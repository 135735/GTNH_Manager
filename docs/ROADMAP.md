# Machine Radar 路线图（世界内 UI → 工厂管理界面）

当前版本（0.7）：精确结构方块、舱室、状态、配方、图标都在快照里；世界内渲染是
「外轮廓线框 + 只填最外层」；工厂列表有自定义分组、组统计、历史采样；
地图升级成多图层（多方块足迹 / 单方块 / 电网 / 物流 / 流体 / Y 层筛选），
并新增效率心电图。下一步是真实电缆/管道拓扑、产量曲线与导航。

## P0 世界内 UI（当前迭代）

- [x] 精确结构方块（GT 校验 + StructureLib 事件）

- [x] 外轮廓线框（按视角算轮廓边，不再逐格描边）
- [x] 线框范围开关：只画点选机器 / 全量（全量时非焦点深度测试 + 淡化区分）
- [x] 线框数量上限（`wireframeMaxMachines`，默认最近 96 台）与分组查询快速路径
- [x] 舱室只对焦点展开，非焦点淡化/关闭
- [x] 舱室朝向在世界内显示
- [x] 机器图标（物品形态）标注
- [x] 游戏内设置界面（M）

## P1 工厂管理界面（GuiScreen，非世界内）

入口：`L` 键、设置界面按钮、`/mradar list`；单机先做。

界面骨架（0.8）：

- [x] 左栏：分组树（全部 / 未分组 / 自定义分区，右键改名/删除/图标）
- [x] 中栏：机器列表（名称、状态、距离、电压、舱室数），搜索/排序
- [x] 多选：Ctrl 切换、Shift 区间、Ctrl+A 全选；行拖到分组完成归组
- [x] 批量：加入/移出分组、远程开关机（单机）
- [x] 右栏：详情（坐标、结构、进度、耗电、产出、维护、IO 计数、舱室统计、历史）
- [x] 统计：分组/全局范围、全局间隔 2.5s + 分帧、调试耗时显示
- [x] 区域预览：分组 AABB / 区块对齐占位（世界内 + 地图 + 列表汇总）
- [ ] 区域编辑（拖边界/命名区域）与区域级产量/能耗汇总
- [ ] 列表列宽可调、每列排序、Shift 多选（已有）、拖拽入组（已有）

需要补的数据：

1. **持久化**：机器清单与结构方块缓存写入 `config/machineradar/index.json`，
   重启后秒开，不必等 120 秒重扫。
2. **区域/维度索引**：按 `dim + 区域名` 聚合，便于"这是哪个基地"。

## P3 多人

- 服务端分帧扫描 → 自定义网络包（分块发送，增量更新）
- 客户端只读快照，结构方块用压缩后的坐标数组传输
- 分组/历史若要多端共享，需要额外同步（目前是纯客户端数据）

## 技术取舍

- 界面用原版 `GuiScreen` + 自绘列表（不引入 ModularUI 依赖，避免和 GT 的版本绑死）；
- 数据全部走现有 `MachineRecord`，界面层不直接碰 `gregtech.*`；
- 分组/历史只在客户端算，服务端只负责提供快照；
- 外轮廓按视角逐帧算（不缓存），换取"永远正确"；面/边数据在 HullMesh 里缓存。
